How to drive it
Click a step
Drum tracks cycle off → on → accent (brighter) → off.
Click a track name
Selects it, so the editor below shows its notes and voice controls.
Piano roll
Click a cell to set the note for that step. Shift-click adds a second note in the same step, making a chord. Click a lit cell to remove it. Click a note name on the left to hear it.
Keyboard
Space plays and stops. A W S E D F T G Y H U J K plays the selected synth voice like one octave of a piano (A = C).
Accent
On the piano roll, shift-click an already-lit note to toggle its accent.
Mute
The small M next to a track name.
Key and scale
They shade the piano roll — bright for notes in the scale, dim for notes outside it, blue for the root — and set which note a step starts on. They change nothing you have already placed, and have no visible effect while a drum track is selected.
Clear all / Load demo
Clear all empties every pattern and the song chain. Load demo puts the original four-bar song back. Both replace everything, and Undo reverses either one.
Follow
In song mode, keeps the step grid on whichever pattern is playing. Clicking a pattern by hand switches it off so your edits stay put.
Saving
Everything autosaves as you work, so a refresh picks up where you left off. Use Saved songs to keep more than one under a name.

Pattern code

The box below writes the whole machine out as text you can copy, keep, or paste back. Drum rows read . for a rest, x for a hit and X for an accent. Synth rows are sixteen note names, - for a rest, + to stack notes into a chord and ! for an accent. A pasted code only changes what it mentions, so a code containing just one drum row replaces only that row.
